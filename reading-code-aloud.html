念代码

白板上你要一边写一边说。念对了，对方不用看屏幕就知道你写的是什么；念错了，他得停下来盯着屏幕重建你说的东西——那几秒就是你的失分点。

唯一的原则：停顿的位置就是括号的位置。数学式子里的分组信息，在纸上靠括号，在嘴上靠停顿。不停顿地一口气念完，对方只能听见一串单词。

停顿落在哪里

mid = left + (right - left) / 2
mid is left▸plus right minus left▸over two

两个停顿正好圈出括号里的那一坨。没有停顿的话，"left plus right minus left over two" 听上去像是四则运算糊成一团。

i = mid / n, j = mid % n
i is mid divided by n▸and j is mid modulo n

两个赋值之间必须停，否则听起来是一个式子。

if (matrix[i][j] < target) left = mid + 1;
if matrix i j is less than target▸left becomes mid plus one

条件和动作之间停一下。注意 = 念 becomes 或 gets，不是 equals——equals 是 ==。

O(log(m * n))
big O of log▸m times n

停顿代替了内层括号。

三个容易读错的

a three times three matrix a three by three matrix

尺寸用 by，运算用 times。同一道题里两个都会出现：
"We're given an m by n matrix… so the flat index runs from 0 to m times n minus one."

mid percentage n mid modulo n　／　mid mod n

percentage 是百分比，和取模没有任何关系。面试官听到会愣一下，然后去看屏幕——你就丢了那几秒。

「呃……」 （停顿，不发声）

中文语气词比 um 更暴露。它直接告诉对方你在用中文思考再翻译。想不出词的时候什么都别发，安静那一秒反而显得从容。
