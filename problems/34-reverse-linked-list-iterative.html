收缩链
原题　给一条单链表的 head，原地反转它，返回新的 head。必须迭代，不能递归。
收缩 ①
反转整条链 → 反转每一条边
链表手里只有 next 指针，所以「反转链表」等价于「把每条 a→b 改成 b→a」，而且边与边互不影响，可以一条一条改。这一环你说得很清楚："for each node I will reverse the pointer to the next"。
O(n)
收缩 ②
一条一条改边 → 维护一个「已翻好的前缀」，每轮把一个节点搬到它前面卡在这
不变量：prev 指向已经翻好那段的头，cur 指向还没翻那段的头。每跑一轮，前缀长一个、后缀短一个。这句是 STEP 4 必须说的。
你说的是 "reduce it to the iteration"——迭代是怎么跑，不是跑的是什么。缺的就是上面这句。
额外空间 O(1)
收缩 ③
不变量 → 初始值
已有：一个空的已翻前缀。求：空前缀的头是什么。
✅ 空前缀的头就是 null——这是收缩 ② 的一行推论，不是一个新决定。
你从没单独说过这一环，它被 "I need a dummy head" 那半句一笔带过了。② 说满，③ 自动就有。
O(1)

代码 · AC 版

public ListNode reverse(ListNode head) {
  // 收缩③：空的已翻前缀，它的头就是 null —— 不是 dummy
  ListNode prev = null;        // ← 上次挂在这一行
  ListNode cur  = head;

  // 不变量：prev = 已翻好那段的头，cur = 还没翻那段的头
  while (cur != null) {
    ListNode next = cur.next;  // ① 先存后继，否则下一行就把路断了
    cur.next = prev;           // ② 把 cur 搬到前缀前面
    prev = cur;                // ③ 前缀长一个
    cur  = next;               // ④ 后缀短一个
  }
  return prev;                 // 退出时 cur==null，prev 就是旧尾 = 新头
}
// TC O(n)　SC O(1)
// 这一行请注释掉重跑一遍 —— 一样 AC，它是死代码
if (head == null || head.next == null) return head;

// head == null  → cur = null，循环跑 0 轮，return prev = null   ✓
// 单节点        → 循环跑 1 轮，return prev = head              ✓
// 「第一个不特殊，它是循环的第 0 次」—— 第 4 次（06 / 20 / 34）

  1. STEP 4 说完，先数名词。刚才那句归约里，有没有一个我自己引进来的东西（dummy / stack / 第三个指针）？有 → 当场补「它的初始值是 ___」「它第一次被读是在第 ___ 行」。答不上来就删掉它再往下。
  2. 走例子之前，先点名那一行。用库里那句："And ___ is the case that breaks if ___."——先出声说「我最不确定的是第 ___ 行」，再设计一个必须经过那一行的输入，然后手指按在代码上一行一行走。题目自带的例子是用来说明题意的，不是用来测代码的。
  3. STEP 5 说满三种，链表的第三种是「刚好两个」。没有 / 刚好一个 / 刚好两个——两个节点是循环第一次真正读 prev 的地方，也是特判挡不住的第一个用例。
