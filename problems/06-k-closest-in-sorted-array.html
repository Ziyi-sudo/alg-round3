这题真正的教训（第一遍的）

别把第一个特殊化。

题目要 K 个，你先求 1 个、再扩 K−1 个——把「第 1 个」和「其余」分成两套逻辑，全部复杂度来自这条缝。

「找最近的那一个」就是「合并的第 0 次」。二分结束后 left / right 已经是两个候选，循环第一轮自动挑出更近的——不需要单独做。

自检信号：当你发现需要写 helper、加变量、特判第一个元素时，停 5 秒问一句——是不是我多加了一个不必要的中间步骤？

这道题的金句

The K closest numbers form a contiguous window — binary-search down to the anchor, then walk two pointers outward.

识别信号：要「连续的一段」+ 数组已有序 → 二分找锚点，两指针向外扩。
这一套管 Closest / K Closest / Bitonic / Kth Smallest In Two Sorted Arrays。

代码 · 第二遍

public int[] kClosest(int[] array, int target, int k) {
  if (array == null || k < 1) return new int[]{};

  int left = 0, right = array.length - 1;

  // ① 二分：收缩到相邻的一对候选　　O(log n)
  while (left < right - 1) {
    int mid = left + (right - left) / 2;
    if (array[mid] == target) right = mid;
    else if (array[mid] < target) left = mid;
    else right = mid;
  }

  // ② 合并：两指针向外走，取 K 次　　O(K)
  int[] result = new int[k];
  for (int i = 0; i < k; i++) {          // ← 填够 K 个就停，不看指针
    if (left < 0)                    result[i] = array[right++];
    else if (right >= array.length)  result[i] = array[left--];
    else if (Math.abs(array[left] - target) <= Math.abs(array[right] - target))
                                    result[i] = array[left--];   // ← <= 平局取小
    else                            result[i] = array[right++];
  }
  return result;
}
// TC O(log n + K)　SC O(K) 输出 / O(1) auxiliary
