句式库

按七步排。红色的 ___ 是每题要换的内容，其余是骨架——骨架背熟，内容现编。不要背整句，背稿的人一被追问就崩。

跟读 遮住后点任意一格单独揭开
STEP 1开场 先申请沉默，再读题。标注过的沉默是专业，没标注的沉默是无进展。
我先通读一遍，会安静一两分钟。
Let me read through this once — I'll be quiet for a minute or two.
还在读，这题铺垫挺长。
Still reading — there's a lot of setup here.
STEP 2复述 用自己的话，不是念题。限定词（any / strictly / distinct）必须复述出来。
为了确认我理解对了：题目给了我们 ___，我们需要返回 ___。
So, to make sure I understand — we're given ___, and we need to return ___.
STEP 3提问 ×2–3 前三条是真问句，问完停下来等答案（B 类：决定模型）。后三条是带假设，说完可以直接往下走（A 类：只影响几行实现）。
如果 ___ 该怎么办？
What should I do if ___?
应该 ___，还是 ___？
Should I ___, or ___?
输入里会有 ___ 吗？
Can the input contain ___?
我假设 ___，这样可以吗？
I'll assume ___ — is that fair?
既然题目写了 ___，那我就当作 ___。
Since the constraints say ___, I'll take it that ___.
我先处理 ___，有时间再回来做 ___。
I'll handle ___ first and come back to ___ if we have time.
STEP 4归约 · 不变量 先推导再下结论，模型名要叫全。后三条是二分家族的通用骨架，讲终止条件永远讲不变量，不讲「什么时候停」。
因为 ___，所以这归约成 ___。
Since ___, this reduces to ___.
不变量是：___ 一定在 ___ 里。
The invariant is: ___ is always inside ___.
循环在 ___ 时继续，在 ___ 时退出。
The loop runs while ___, and exits when ___.
我移到 mid 本身，不越过它——mid 自己可能就是答案。
I move left or right to mid, not past it — mid itself might be the answer.
既然我不丢弃 mid，循环就必须在 left 和 right 还相邻时停下。
Since I never discard mid, the loop has to stop while left and right are still adjacent.
STEP 5边界 主动提，而且要给具体例子——只说「边界是返回 0」很虚。说完手指在代码里指一遍。
写代码之前，说一个边界：___ 的时候返回 ___，不是 ___。
Before I code — one edge case: ___, we return ___, not ___.
具体来说，___ 这个例子的答案是 ___。
Concretely, for ___ the answer is ___.
STEP 6复杂度 · 递球 报完复杂度把球递回去，然后停下来等他回答。全套里性价比最高的 5 秒。
时间 O(___)，空间 O(___)。
Time is big O of ___, space is O(___).
开始写之前，你觉得这个方向可以吗？
Does that sound reasonable before I start coding?
STEP 7测试 面试里没有 run 按钮。四个例子：正常 / 找不到 / n = 1 / 空输入。最后一条是加分句——说明你知道这个 case 为什么在这儿。
我走几个例子验证一下。
Let me walk through a few cases.
___ 这个例子，结果是 ___。
For ___, we get ___.
而这个 case，如果 ___ 就会挂。
And this is the case that breaks if ___.
写码中只说意图，不念语法 每 3–5 分钟一句就够。他看得懂代码，他让你讲是想看决策依据。
中点这么算是为了防溢出。
I'm computing mid as left + (right − left) / 2 to avoid overflow.
这个分支把左半边扔掉。
This branch discards the left half.
这是给 ___ 的防御。
And this is the guard for ___.
追问Follow-up 答不出细节没关系——能说出方向就拿到这一问的分了。
如果你想要的是 ___，我会 ___。
If you wanted ___ instead, I'd ___.
保命卡住 · 自我纠正 沉默是面试里最贵的东西。自我纠正是加分项——所以不要道歉，直接改。
让我想一下，我想把 ___ 弄对。
Let me think for a second — I want to get ___ right.
让我倒回去一下——我想先走一个例子。
Actually, let me back up — I want to walk through an example first.
等等，这个没处理 ___ 的情况，我改一下。
Actually, wait — that doesn't handle ___. Let me fix that.
我还没看到最优解，先从暴力开始找冗余。
I'm not seeing the optimal approach yet — let me start with brute force and look for the redundant work.
时间快到了，你希望我优化，还是多走几个例子？
Given the time, should I optimize, or walk through more test cases?
