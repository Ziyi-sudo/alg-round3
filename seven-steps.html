面试七步

开录音前扫一眼

只看步骤名，别读内容。目标不是讲得漂亮，是七步一步都不跳——讲得烂但完整，好过讲得顺但残缺。

STEP 1开场0:00

先申请沉默，再读题。没这句，沉默 = 卡住了。

Let me read through this once — I'll be quiet for a minute or two.

STEP 2复述1:45

用自己的话，不是念题。限定词要复述出来（any / strictly / distinct）。

So, to make sure I understand — we're given ___, and we need to return ___.

STEP 3提问 ×2–32:15

只问会改代码的。B 类（决定模型）真问、真等答案；A 类（几行实现）带假设问。

B 类　Can it contain duplicates? / What should I do if ___?

A 类　I'll assume ___ — is that fair?

排期　I'll handle ___ first and come back to ___ if we have time.

STEP 4归约3:30

先推导再下结论，然后叫出模型全名。「排序了所以二分」是断言，不是推导。

Since ___, this reduces to ___.

The invariant is: ___ is always inside ___.

STEP 5边界5:30

主动提，而且给具体例子。说完手指在代码里指一遍——嘴上说了手上要写。

Before I code — one edge case: for ___, we return ___, not ___.

STEP 6复杂度 · 递球6:00

报完复杂度，把球递回去，然后停下来等他回答。全套里性价比最高的 5 秒。

Time is O(___), space is O(___). Does that sound reasonable before I start coding?

STEP 7测试25:00

面试里没有 run 按钮。四个例子：正常 / 找不到 / n = 1 / 空输入。n = 1 必跑。

Let me walk through a few cases.

写码那 15 分钟 只说意图，不念语法。每 3–5 分钟一句就够。 I'm handling the duplicate case here.
卡住时 · 必须出声 沉默是面试里最贵的东西。 Let me think for a second — I want to get the boundary right.
本周只盯 we're given（被动语态）。其余错误全部允许，一次只盯一条。
ALG ROUND 3 · 七步一步都不跳
